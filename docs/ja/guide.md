# 利用ガイド

## 目的と撮影条件

画像から候補を抽出した後、輪郭形状・傾き・底面位置と明確な浮き量の許容範囲を組み合わせることで、認識の安定性と再現性を向上させます。カメラ位置を固定し、瓶の基準線を設定する必要があります。照明変動に対する完全な不変性を保証するものではなく、設置環境ごとに閾値と照明を検証してください。黒色キャップも対象とするプロジェクトですが、現行の `_detect_cap()` は**赤色抽出のみ**を実装しています。赤色用HSV閾値で黒色を認識できるわけではありません。

## 画像認識の処理手順

1. BGR画像をHSVに変換し、赤色の2範囲 H=0–10、H=170–180（S=120–255、V=70–255）を結合します。
2. 5×5カーネルでオープニング・クロージングを行い、外部輪郭を抽出します。面積500 pixel²以下の輪郭を除外します。
3. 各輪郭に `cv2.minAreaRect()` を適用し、傾き3°未満、幅/高さ比2.3–2.8を確認します。
4. 回転矩形の最下部2頂点のY座標平均からキャップ底面を求めます。
5. `lift_mm = (BOTTLE_RIM_Y - cap_bottom_y) / MM_TO_PIXEL` で浮き量を算出します。
6. 形状条件を満たしたうえで、閉栓0.5±1.0 mm、開栓3.5±1.0 mmの条件を独立に評価します。

これらは初期設定値であり、あらゆる機構に共通する許容差ではありません。基準線と換算係数は撮影系に合わせて設定してください。条件を満たす複数輪郭を評価し、最後に処理した輪郭を代表値として保持します。`get_detections()` から各輪郭の結果を取得できます。

## 検査と状態の更新

`inspect(mode)` は1フレームを取得して開閉両方の状態フラグを更新します。`is_open()`、`is_closed()`、`is_safe()`、`get_status()` は保存された結果を返し、再撮影しません。キャップを検出できなかった場合は検査不合格です。モードは `closed`、`opened` を指定し、旧表記 `open` は `opened` に正規化されます。

## 設定の保存と読み込み

`get_parameters()` で現在の設定を取得し、`set_parameters({...})` や個別setterで変更します。`save_parameters(path)` / `load_parameters(path)` はJSONを使用します。gRPCクライアントの保存・読込先は**クライアント側**です。
