# API and configuration

`CapInspector.inspect(mode)` captures and processes a frame and returns whether the specified `"closed"` or `"opened"` criterion is met. The same inspection updates both stored state flags. `is_open()`, `is_closed()`, `is_safe()`, and `get_status()` query the latest result without reprocessing.

`get_image()` and `image_stream()` provide image access. gRPC methods are exposed using `grpc_frame`.

Use `get_parameters()` and `set_parameters()` for configuration, or the individual setters `set_camera_id()`, `set_bottle_rim_y()`, `set_mm_to_PIXEL()`, `set_target_close_mm()`, `set_target_open_mm()`, `set_tolerance_mm()`, and `set_mode()`. `save_parameters()` and `load_parameters()` support JSON configuration files.

The gRPC client type stub (`client.pyi`) is generated by the package maintainer using `server_grpc/make_pyi.py` and included in the distribution. Users do not need to generate it.
