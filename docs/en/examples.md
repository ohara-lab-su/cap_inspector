# Examples

- `examples/server_example.py`: start the gRPC server.
- `examples/gui_client.py`: remote production viewer.
- `examples/client_example.py`: remote inspection.
- `examples/set_parameters_client.py`: individual and batch setters.
- `examples/parameter_client.py`: JSON configuration.
- `examples/roi_client.py`: legacy filename; sets the rim reference and scale, not an ROI.
